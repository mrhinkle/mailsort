# mailsort-later

The honest middle. Most mail is neither important nor junk, and pretending otherwise is what makes
triage systems collapse into two useless piles.

## Identify

Everything that reaches the end of the decision order in `mailsort`: legitimate, addressed to the
owner, no reply expected, no deadline, no transaction.

## Action

`FILE` to Later and archive. Then the part everyone skips: **give it a review cadence.** Later is only
safe if it is actually reviewed — otherwise it is a black hole with a friendlier name.

- Default: one batch pass, once a week.
- Report it as a count with the three largest senders, never as a list.
- Anything sitting in Later for **30 days** untouched is evidence, not backlog: propose a permanent
  rule for that sender (News, CC, or Black Hole). If the owner has not read it in a month, they were
  never going to.

## The promotion check

Before filing, ask one question: *if this sat unread for a week, would anything break?* If yes, it is
not Later — recheck Don't Miss and Needs Reply. This single check catches most misfilings.
